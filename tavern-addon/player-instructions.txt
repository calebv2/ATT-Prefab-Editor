PREFABULATOR 1.0.24 — PLAYER ADD-ON AND MOD

Use this package when the player and server have separate game folders.
It includes the Tavern Launcher add-on and player mod 2.3.10. Ask the server
owner to install PrefabEditorCore from Server-Mod-Only if needed.

INSTALL OR UPDATE
1. Close the game and Client Tavern Launcher.
2. Extract this ZIP beside the Client launcher EXE. Merge the addons folder
   and replace its Prefabulator files. Keep the entire addons/prefab_editor
   folder, including payload and runtime.
3. Open the Client launcher. If Prefabulator is missing, enable it under
   Addons, save, and restart the launcher.
4. Choose your server in the Client launcher. Open Prefabulator, paste your
   moderator code or owner console token, and click Connect.
5. Check the game folder and click Install or update player mod. Do this
   even if you already have an older player mod.
6. When you see Editor connected, join the server and press F1. Keep
   Prefabulator open. If the game is already open, relaunch it.

If you host the server on this PC, tick I host this server on this PC
before entering the owner token. Your game can still use its regular join
address. A moderator code selects its own server automatically.
Save access and connect automatically on this server is optional. Windows
encrypts saved access for your account. In the dashboard, Forget saved access
removes it.

IN GAME
- F1 opens the editor above your character in flat-screen mode.
- Select an item, release the mouse, then drag an arrow or square to move it.
  Drag a ring to rotate. Esc cancels a handle drag.
- Teleporter: stand at the destination and click Capture my position.
  Select the placed teleporter and click Link selected teleporter to destination.
- Trading: select a trade deck, choose the item, then set price, quantity and stock.
- Build > Prefabs loads saved layouts. Build > Strings opens individual item
  strings from a file, a folder or your clipboard.

CONNECTION TROUBLE
Use Connection diagnostics before login or Diagnostics on the dashboard.
If you select another game server, click Change server and reconnect.
Use Retry connection to restart the editor connection, then relaunch the game.

OWNERS
Open Manage moderator access to create a private code, choose permitted tabs
or revoke access. Console commands is a separate permission that can run any
server command. Keep owner tokens and moderator codes private.

A separate server already running core 1.6.7 can keep it. Existing saves,
teleporter links and moderator codes carry over.
