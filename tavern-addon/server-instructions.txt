PREFABULATOR 1.0.24 — SERVER MOD ONLY

This package contains PrefabEditorCore 1.6.7 for the dedicated game server.
A server already running core 1.6.7 can keep its installed copy.
If the player and server share one game Mods folder, use All-in-One-Shared-Mods.

INSTALL OR UPDATE ON WINDOWS OR LINUX
1. Stop the game server.
2. Open this ZIP's Mods folder. Copy PrefabEditorCore.dll into the server
   game's Mods folder. The server game folder contains A Township Tale_Data.
3. Start the server. Look for PrefabEditorCore 1.6.7 up in the startup log.
4. Reconnect Prefabulator and other console sessions.

On the playing computer, install Player-Addon-and-Mod beside the Client
Tavern Launcher EXE. Open Prefabulator and connect using the owner console
token. From Manage moderator access, create a private code for each moderator
and grant the tabs they need. Console commands allows any server command,
so it is granted separately. Keep the owner token private.

Keep world saves, UserData, teleporter links and server keys in place.
Info Boards requires LiveInfoBoards on the server.
Core 1.6.7 includes the owner console duplicate-command fix from 1.0.23.
