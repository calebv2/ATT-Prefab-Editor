PREFABULATOR - ALL-IN-ONE FOR ONE SHARED GAME / MODS FOLDER

Use this ZIP when the server and player use the SAME game installation and Mods
folder. It includes both DLLs, player preview assets and the launcher add-on.
Use the separate Player and Server ZIPs when their game folders are different.

INSTALL OR UPDATE
1. Stop BOTH the server and player game. Close Tavern Launcher too.
2. Copy this ZIP's Mods folder into the shared GAME folder containing
   A Township Tale_Data. Merge folders and replace the old files if asked.
   The shared Mods folder must contain BOTH:
     PrefabEditorCore.dll - server tools
     PrefabEditor.dll     - player editor
   Keep PrefabEditorCatalog.json and PrefabEditorImages beside them.
3. Copy this ZIP's addons folder beside the CLIENT Tavern Launcher EXE.
   Keep the whole addons/prefab_editor folder, including payload.
4. Start the server normally. Open the player launcher, enable Prefabulator
   under Addons if needed, and restart the launcher if asked.
5. Choose your server in the CLIENT launcher, then open Prefabulator.
   It uses that address automatically. Enter your owner console token or
   paste your personal moderator code and Connect. Wait for CONNECTED.
6. Launch the player game, join your server, and press F1 to open the editor.
   Keep Tavern Launcher and Prefabulator open; minimizing them is fine.

The server core stays idle in the player process. The player editor stays idle
in the dedicated server process. Both DLLs can stay in the same Mods folder.
Shared-folder setup uses the Windows player launcher; it does not combine the
server and client executables or change how your server normally launches.

UPDATES FROM PREFABULATOR
The all-in-one add-on's update button installs BOTH DLLs into the game folder
you choose. Stop both server and game before using it, then restart the server,
reconnect Prefabulator, and launch the game. You can also repeat steps 1-3.

Keep your existing UserData, world saves, teleporter-links.json and admin access
settings. Existing teleporters do not need relinking. Never share console tokens.

Owner: Manage Admin Access creates personal moderator codes and tab permissions.
Give other players the Player-Addon-and-Mod ZIP and their own code; they only
need the all-in-one ZIP if they also share a server/player Mods folder.

MOVING ITEMS
Click an item to select, release the mouse, then drag arrows for one axis,
colored squares for two axes, or the white center square for free movement.
Drag rings to rotate. Esc cancels a handle drag.

CONNECTION TROUBLE
Choose the server in the CLIENT launcher first. Prefabulator uses that address
automatically; you do not type it twice. Blank means this computer (127.0.0.1).
A moderator code also selects its own server in the launcher when you Connect.
If you change servers after connecting, click Change server / reconnect before
joining and use access for that server. Saved tokens stay tied to their server.
CONNECTED now shows the local connection-file path and editor address.
Retry editor connection repairs a missing file while its helper is running.
After connecting, relaunch the player game if it was already open.
Keep payload, runtime and all included folders when replacing the add-on.

MISSING PREFABULATOR BUTTON
Version 1.0.16 fixes an add-on load failure in the packaged Tavern launcher.
Close the CLIENT launcher, replace addons/prefab_editor beside its EXE, then
reopen it. Under Addons, enable Prefabulator and Save, then restart the client
launcher. The Prefabulator button appears beside TavernKeeper. No Python installation
is needed.

LOCAL SERVER ON YOUR PLAYING COMPUTER
If you join using a public/LAN IP but the console only connects on localhost:
1. Keep the working game server address in the main Client launcher.
2. Open Prefabulator. Tick "I run this server on THIS computer" before entering
   the owner console token. The console address becomes 127.0.0.1.
3. Enter the token and Connect. Optional: Save my access token remembers this
   pairing for this game server. Keep Prefabulator open, then join and press F1.
Only tick this if the game server runs on the computer you are using to play.
Changing game servers clears the pairing and token. Use Change server / reconnect
if a different server was selected while already connected.

CONSOLE TAB - REQUIRES PLAYER 2.3.7 AND SERVER CORE 1.6.6
Update BOTH mods before using Console; restart the game server after its update.
In game, press F1, open Console, enter one command, and click Run command. The
reply appears below. Use Paste command, Previous/Next command, Copy output and
Clear output as needed. Commands are sent once; check the result before retrying
if the connection fails. History is kept only until the game closes.
Owner: Manage Admin Access > select the moderator > tick Console > Save permissions.
Existing moderator codes stay valid, but Console is OFF until you enable it.
Console allows unrestricted server commands. Enable it separately from Select all
tools. Only the owner can manage access profiles. Give Console only to admins you trust with full
server command access.

PREFABS AND STRINGS
Build now has Prefabs and Strings sections. The old JSON import is called Prefabs;
your existing saved prefab files still work.
To spawn a local item string: press F1 > Build > Strings > Browse string file or
Browse string folder. Choose the folder containing your .txt files. Search by
name, select a variant, then click Spawn selected string. It appears 3 m in front
of the editor camera. You can also use Read strings from clipboard.
Files with several labeled strings show separate choices. Instruction-only files
are skipped. Generator code is ignored and file warnings are shown before spawning.
Each click spawns ONE selected variant. String spawning uses the Build permission.

CONNECTION DIAGNOSTICS AND MODERATOR ACCESS
Open Connection diagnostics in Prefabulator to check the selected game's DLLs,
its connection file, running helpers and local ports. Copy report if you need
help. A shared Mods folder normally contains one player DLL and one server DLL.
Owners can create and edit moderator profiles in Manage Admin Access. Use the
permission checkboxes to choose the tools each moderator can use.
For 1.0.22, close the Client launcher and replace its complete addons/prefab_editor
folder. Users already on 1.0.21 can keep their installed DLLs.
