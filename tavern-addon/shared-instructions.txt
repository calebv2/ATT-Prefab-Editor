PREFABULATOR 1.0.24 — ALL-IN-ONE SHARED MODS

Use this package when the server and player share one game installation and
Mods folder. It includes player mod 2.3.10, server core 1.6.7, and the add-on.

INSTALL OR UPDATE
1. Stop both the server and the player game. Close Client Tavern Launcher.
2. Copy this ZIP's Mods folder into the shared game folder that contains
   A Township Tale_Data. Merge and replace files if asked. Keep both DLLs,
   PrefabEditorCatalog.json and PrefabEditorImages in Mods.
3. Copy this ZIP's addons folder beside the Client launcher EXE.
   Keep the full addons/prefab_editor folder, including payload and runtime.
4. Start the server and open the Client launcher. If Prefabulator is missing,
   enable it under Addons, save, and restart the launcher.
5. Select your server, open Prefabulator, and connect with the owner console
   token or a private moderator code. If you host on this PC, tick
   I host this server on this PC before entering the owner token.
6. When you see Editor connected, join the game and press F1. Keep
   Prefabulator open. If the game is already open, relaunch it.

You can also replace both DLLs using Install or update both mods in the
dashboard. Stop both the server and player game before using it. Then start
the server and reconnect Prefabulator. Each DLL starts only in its game role.

QUICK HELP
- In flat-screen mode, F1 opens the editor above your character.
- In Teleporter, stand at the destination and click Capture my position.
  Select the placed teleporter and click Link selected teleporter to destination.
- Use Connection diagnostics before login or Diagnostics on the dashboard.
- If you choose a different server, click Change server before joining it.
- Owners can create or revoke private codes under Manage moderator access.
  Give moderators on separate computers the Player-Addon-and-Mod package.

Keep UserData, world saves, teleporter links and server keys in place.
Existing teleporter links and moderator codes carry over.
